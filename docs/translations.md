# Writer interface translations

Writer uses Lingui 6.9 macros, generated English/context IDs, PO source catalogues and compiled ICU JSON. Interface language is independent of a manuscript's `lang`: citation terms, hyphenation, manuscript text, exported prose, source metadata, record paths and user-created labels are not translated.

## Runtime

`apps/writer/src/i18n/app.ts` injects the single Lingui instance exported by the shared UI package. English JSON is synchronous. French, German, Spanish, Japanese, Korean, Brazilian Portuguese (`pt`), Russian and Simplified Chinese (`zh`) are lazy JSON chunks served by the same deployment. Browser language negotiation is used until an explicit choice is saved in `mdbase-writer:interface-locale`. Unavailable browser storage does not block selection. A failed chunk request keeps the current language and saved choice.

The language picker is available on the home/sign-in chrome and in workspace settings, so it does not compete with the manuscript toolbar on narrow screens. The root provider covers dialogs and portals. The editor's separately mounted selection toolbar uses the same instance. Language changes reconfigure CodeMirror's phrases and editor chrome in place rather than recreating the editor or changing its text/history. The runtime updates `<html lang>`; display-only dates, numbers and relative times use the interface locale.

The shared runtime is given `i18n` from `@mdbase-dev/ui/i18n` (the same core singleton), so core macros, React context and presentation helpers share one translator without custom module aliases. English is initialized before non-React helpers run; tests load that same real runtime.

## Authoring

From `apps/writer`:

```sh
pnpm i18n:extract
# Author/review src/i18n/locales/<locale>/messages.po locally.
pnpm i18n:compile
pnpm i18n:check
```

`i18n-policy.json` explicitly allowlists reviewed unchanged keyboard key legends (including Japanese), `ID`, Word/DOCX, German cognates (including “Problem”), Spanish/Portuguese Editor/Zoom, Portuguese Layout / “via mdbase Connect”, and reviewed French cognates (e.g. Collection, Source, Citation, Note, Page, Article) / “via mdbase Connect”. It does not exempt whole catalogues or English prose. New identical terms need review; for example, English “click” in a Chinese shortcut hint is not accepted as a keyboard key name.

Use `Trans` for complete sentences with rich markup and ICU plurals for counts. Use `t` in presentation helpers and accessible labels. Add semantic context to ambiguous short messages. Module-level option labels must be lazy getters or rendered on demand, never translations captured before locale selection. Stable command IDs, keyboard bindings, format keys and record values remain untranslated.

Shared UI owns its catalogues. The runtime composes `uiCatalogues` from `@mdbase-dev/ui/i18n` via `libraries`; no library source or provisional collection-copy dictionary is extracted into Writer. App and library target chunks load together before activation. Collection names remain user data, as does the protected `{#fig-plan}` Markdown example. The vendored UI integration snapshot is `vendor/mdbase-dev-ui-0.1.0-beta.141-852df21f.tgz` (SHA-256 `5f644e4059ab7d66b3153d032a5b9eb1ca896e0129aa317ba7250ca676a89ce7`). Portal verified strict all-nine catalogue checks and builds for both shared libraries, including the Reset delta; this replaces the old fallback snapshot. Strict runtime composition correctly rejects mismatched compiled entries: an untranslated app/shared catalogue must not silently override an authored one. Source comparison against portal's current shared catalogues found one real discrepancy: Russian `Remove` (`t_YqKh`) was `Убрать` in Writer vs `Удалить` in shared UI; Writer was explicitly aligned to `Удалить`. The other seven locales agreed on all overlapping IDs. The shared CLI's `check --compose 'node_modules/@mdbase-dev/ui/dist/locales/{locale}/messages.json'` checks every app/library overlap in all nine locales as part of normal check/build; runtime tests also activate all eight target languages without mocking or bypassing collision checks. The temporary app-local overlap script was replaced by this shared gate. Never bypass the collision guard to make an integration test pass.

## Current integration status

All eight authored locale branches are merged. English and each target PO have exactly 658 active messages after extraction: no empty, missing or retired IDs. Japanese “via mdbase Connect” was translated to “（mdbase Connect 経由）” rather than allowlisted; the German `{MOD_LABEL}-click` action is authored as `{MOD_LABEL}-Klick`. Reviewed keyboard legends and identical Word/DOCX terms remain unchanged, not padded to evade checks. Removed unreachable `one` plural arms in Japanese (3), Korean (1) and Chinese (22), preserving each authored `other` arm and the explicit `=0` case. These languages have only the `other` cardinal category. App completeness does not certify the shared tarball or constitute a nine-language release. The scope includes Writer-owned screens, editor controls, accessible names, save/recovery/export notices, core-owned interface guidance, shared collection UI copy and language controls. Compiled fallbacks are not evidence of target completeness.

The shared kit is vendored from Connect commit `5be277b8` as `vendor/mdbase-dev-i18n-0.1.0-beta.141-5be277b8.tgz` (SHA-256 `953044eb06763e66b93032387a53ccdbe0e02cf524ccac126dd6396138493c5d`). This supersedes `8785bd19`, retaining built-in composition checking and tracking rendered React state fields individually: `notice.text` is checked without misidentifying sibling `Notice.tone` CSS/icon/branch discriminators as copy. Explicit-instance macros, nested ICU helpers and instance fields remain supported. Its config preset, runtime, picker, formatters and lazy CodeMirror phrases are adopted. This kit fixes the old symlink-sensitive CLI entry guard: scripts use the bare `mdbase-i18n` command, and the temporary launcher has been deleted. A smoke test requires invalid commands to fail. Strict completeness/contracts/source checks run in normal check/build/CI; CI also rejects drift in committed generated JSON. These gates reject missing translations rather than accepting English fallback. Shared UI feedback/theme/palette/collection internals use the shared library's own CatalogueSource; no app-local copy dictionary remains. Writer-owned core diagnostics carry serializable copy codes across the worker boundary and are translated in the main-thread presentation adapter. Core/CLI English remains unchanged. Export warning formatting is separate from manuscript materialization; Pandoc warnings are also translated on the main thread, not inside its compiler worker. Raw authority/Typst diagnostics and exported document content never enter the interface catalogue.

The demo-only `apps/writer/scripts/i18n-browser-test.mjs` blocks non-local requests and covers synchronous English, Japanese CodeMirror, language persistence, unchanged manuscript source, the narrow settings picker and a failed locale-chunk request. After adopting the strict UI tarball, a fresh `--force` Vite server on port 19400 and new Playwright contexts passed the full scenario: authored Japanese home/editor and CodeMirror, German settings at 1440px and 390px, persistence through reload, unchanged manuscript, Chinese settings/slash commands, and English retention on an intentionally aborted German chunk followed by successful Japanese retry. Japanese/German screenshots were inspected for clipping and reachable controls (`apps/writer/out/i18n/`, ignored). This demo blocks remote compiler/authority traffic and is interface acceptance, not production export/native-device qualification. Force-restart Vite after changing vendored packages to avoid stale prebundles.
